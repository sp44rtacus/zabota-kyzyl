> **Ведомственная принадлежность:** Департамент по социальной политике мэрии города Кызыла (Республика Тыва).  
> **Юридический адрес ведомства:** 667000, г. Кызыл, ул. Кочетова, д. 29.  
> **Назначение:** Автоматизация приёма, обработки, распределения и контроля исполнения заявок на бытовую, социальную и гуманитарную помощь льготным категориям граждан города Кызыла, координация волонтерских отрядов и формирование отчетности для руководства Мэрии.

## 🏛️ 1. Архитектура системы

Система построена по строгой трехзвенной сервисно-ориентированной архитектуре (Layered Clean Architecture):

```
┌────────────────────────────────────────────────────────────────────────┐
│                   КЛИЕНТСКИЙ СЛОЙ (FRONTEND SPA)                       │
│  React 18 + TypeScript + Vite + Tailwind CSS + Leaflet.js + Chart.js   │
│  - Портал жителей (Подача SOS-заявок с аудиозаписью на JS, Трекер УИН) │
│  - Кабинет волонтера (Лента "По пути", сдача фото "До/После", чат)     │
│  - Рабочий стол инспектора (Канбан-доска, сплит-верификация)           │
│  - Аналитический дашборд директора (Тепловая карта Кызыла, Excel)      │
│  - Режим для слабовидящих по ГОСТ Р 52872-2019                         │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ REST API / JWT Bearer
┌───────────────────────────────────▼────────────────────────────────────┐
│                  СЕРВЕРНЫЙ СЛОЙ (BACKEND FASTAPI)                      │
│  FastAPI (Async Python 3.12) + Pydantic v2 + SQLAlchemy 2.0 ORM        │
│  - Модуль RBAC (Role-Based Access Control): Житель, Волонтер,          │
│    Инспектор, Руководитель Мэрии                                       │
│  - Модуль автоматической документации Swagger UI (/docs)               │
│  - Генератор официальных справок и грамот в PDF (ReportLab)            │
│  - Генератор сводной отчетности для Мэрии в Excel (OpenPyXL)           │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ SQLAlchemy Engine
┌───────────────────────────────────▼────────────────────────────────────┐
│                    СЛОЙ ДАННЫХ (DATABASE LAYER)                        │
│  PostgreSQL 14+ / SQLite (Zero-Config для демонстрации и защиты)       │
│  10 микрорайонов Кызыла, категории льготников, заявки, назначения,     │
│  пункты обогрева, чаты координации, электронные грамоты                │
└────────────────────────────────────────────────────────────────────────┘
```

## 🗺️ 3. Специфика города Кызыла в системе

1. **Реальная картография микрорайонов**:
   - Центральный район (ул. Ленина, ул. Кочетова, ул. Дружбы)
   - ЛДО (Левобережные дачные общества — 1–4 остановки)
   - ПДО (Правобережные дачные общества)
   - пгт. Каа-Хем и Ближний Каа-Хем
   - Вавилинский затон (сектор частной жилой застройки)
   - МЖК, Южный, Восточный, Горный.
2. **Публичная сеть пунктов обогрева Мэрии**:
   - Центральный пункт (ул. Кочетова, д. 29)
   - Центр помощи семье и детям «Сайзырал» (ул. Колхозная, д. 45)
   - Мобильный пункт МЧС / Мэрии (Вавилинский затон, 6-я линия)
   - Социальный павильон ЛДО (4-я остановка).
3. **Учет актуальных льготных категорий**:
   - Семьи участников Специальной военной операции (СВО);
   - Ветераны труда РФ и Республики Тыва;
   - Одинокие пенсионеры старше 80 лет;
   - Инвалиды I и II групп (маломобильные граждане);
   - Многодетные семьи.

## 🚀 4. Инструкция по быстрому запуску на компьютере

### Вариант А: Быстрый запуск в 1 клик (PowerShell)
Просто запустите скрипт `run.ps1` в корневой папке проекта:
```powershell
.\run.ps1
```
Скрипт автоматически:
1. Запустит бэкенд на FastAPI (`http://localhost:8000/docs`);
2. Запустит фронтенд на React (`http://localhost:5173`);
3. Откроет браузер на главной странице портала.

---

### Вариант Б: Ручной запуск компонентов

#### 1. Серверная часть (Backend):
```bash
cd backend
py -3.12 -m uvicorn app.main:app --reload --port 8000
```
- Интерактивная документация Swagger UI: **http://localhost:8000/docs**
- ReDoc документация: **http://localhost:8000/redoc**

#### 2. Клиентская часть (Frontend):
```bash
cd frontend
npm install
npm run dev
```
- Веб-приложение: **http://localhost:5173**

## 🎓 5. Сценарий демонстрации проекта перед комиссией (5 минут)

1. **Шаг 1. Публичный портал жителей (`/`)**:
   - Продемонстрируйте шапку: переключите **«Версию для слабовидящих» (ГОСТ Р 52872-2019)** и контрастность.
   - Покажите интерактивные счетчики выполненных заявок и охваченных районов Кызыла.
   - Нажмите **«Карта пунктов обогрева»** — покажите маркеры на карте Кызыла с адресами и часами работы.
   - Нажмите **«SOS: Экстренная помощь»** — покажите форму подачи заявки, нажмите кнопку **«Записать голосовое сообщение»** (продемонстрируйте запись с микрофона браузера и прослушивание).
   - Введите тестовый номер `KZ-2026-1042` в поле «Проверить статус» — покажите визуальный Stepper движения заявки.

2. **Шаг 2. Кабинет волонтера**:
   - Нажмите в верхней плашке «Демо: Сменить роль» -> выберите **«Волонтер (Ондар Ч.)»**.
   - Покажите ленту заявок с фильтром **«По пути (мой район)»** и откликнитесь на задачу.
   - Перейдите во вкладку «Мои активные задачи» — покажите раскрытие полного адреса, чат с инспектором и форму сдачи отчета с загрузкой **«Фото ДО»** и **«Фото ПОСЛЕ»**.
   - Перейдите во вкладку «Дневник практики» и нажмите **«Скачать Справку о практике (PDF)»** — откроется официальный PDF-бланк с гербом Мэрии Кызыла, часами и подписью.

3. **Шаг 3. Рабочий стол инспектора**:
   - В плашке демо выберите **«Инспектор (Куулар А.)»**.
   - Покажите **Канбан-доску** с колонками и красной подсветкой SOS-заявок.
   - В колонке «Проверка фото» нажмите **«Сплит-экран проверки»** — откроется Side-by-Side сравнение снимков «До» и «После» с аудиоплеером обращения.
   - Нажмите «Утвердить отчет (+2 ч.)» — часы автоматически зачислятся волонтеру.

4. **Шаг 4. Аналитический модуль директора Мэрии**:
   - Выберите роль **«Директор (Монгуш Б.)»**.
   - Продемонстрируйте **Тепловую карту (Heatmap)** Кызыла с зонами высокой концентрации заявок (Вавилинский затон, ЛДО).
   - Покажите графики Chart.js (динамика обращений и распределение по категориям СВО/ветеранов).
   - Нажмите **«Экспорт сводки в Excel (.xlsx)»** — файл мгновенно скачается и откроется с отформатированными таблицами, шапкой ведомства и формулами.

## 🔒 6. Безопасность и соответствие стандартам РФ

- **152-ФЗ «О персональных данных»**: Точные адреса (номер дома и квартиры) и телефоны заявителей анонимизируются в публичном доступе и открываются исключительно назначенному волонтеру после одобрения инспекцией.
- **ГОСТ Р 52872-2019**: Доступность цифрового контента для людей с инвалидностью и слабовидящих граждан.
- **Безопасность авторизации**: Хеширование паролей алгоритмом **bcrypt (12 раундов соли)**, защита эндпоинтов через **JWT-токены (HS256)** с RBAC-верификацией ролей.
